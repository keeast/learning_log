# NLP基础知识
NLP（Natural Language Processing）：自然语言处理    
- **分词**：如何把文本拆成计算机能处理的最小单位
- **n-gram**: 如何计算一句话出现的概率是否合理
- **词向量**： 如何让计算机理解词语之间的“含义”和“关系” 
## 分词（Tokenization） 
作用：将连续的文本切分成有意义的最小单元（**Token**）   
- 英文分词：空格法  
相对简单，但要注意标点和缩写  
    ```python
    # 基础英文分词
    text_en = "I don't like rainy days."
    # 简单的按空格分并不完美
    print(text_en.split()) 
    # 输出: ['I', "don't", 'like', 'rainy', 'days.']
- 中文分词：使用分词器  
我们通常借助第三方库 Jieba 来完成   
    ```python
    # 基础中文分词
    import jieba
    text_zh = "我不喜欢下雨天。"
    print(jieba.cut(text_zh))
    # 输出: 不 喜欢 下雨 天
- 进阶：字词分词（BPE / WordPiece） 

    现代大模型（如GPT、BERT）不只用"词"，还会切分成"子词"（Subword）。例如 unhappiness 会被切成 ['un', 'happiness']，这样即使遇到生僻词，也能通过词根猜出意思。这是目前最主流的分词策略。

## n-gram语言模型——赋予机器语感
1. 举例：假设我给你三个词："我"、"吃"、"饭"，让你按顺序排列，你会排成"我吃饭"。为什么？因为你根据经验判断，"我"后面跟"吃"的概率，远大于"吃"后面跟"我"的概率。 

2. 定义：n-gram 就是用来计算这个概率的数学模型。它基于**马尔可夫假设：一个词出现的概率，只依赖于它前面的 n-1 个词。**   
    - Unigram (n=1)：只看词本身，不考虑上下文。
    - Bigram (n=2)：看前 1 个词。如 P(吃 | 我) 的概率。
    - Trigram (n=3)：看前 2 个词。如 P(饭 | 我, 吃) 的概率。

3. 计算方式：   
    假设语料库只有两句话：
    ```
    我 喜欢 苹果
    我 喜欢 香蕉
    ```
    求 P(喜欢 | 我) 的概率：

    公式：P(w2 | w1) = Count(w1, w2) / Count(w1)

    Count("我") = 2

    Count("我", "喜欢") = 2

    概率 = 2 / 2 = 1.0 （100%出现）

4. n-gram 的致命缺陷与平滑（Smoothing）  
    如果测试集里出现 "我 喜欢 榴莲"，而训练集里没出现过"榴莲"，那么概率就是 0（连乘后直接变0）。    
    解决办法：拉普拉斯平滑（加1平滑）——让所有没出现过的词也有一个很小的概率值，避免零概率灾难。

## 词向量（Word Embedding）——从编号到语义地图
- 独热编码（One-Hot）：
    ```
    我 爱 你
    我：100
    爱：010
    你：001
    ```
    缺点：
    - 维度且稀疏，计算量大
    - 无法表达词与词之间的关系
- 词向量（Word Embedding）：
    - 维度低，计算量小
    - 可以表达词与词之间的关系

    核心思想是：一个词的含义，由它的上下文决定（You shall know a word by the company it keeps）。

    它将每一个词映射为一个**稠密的、低维的浮点数向量**（如 300 维）。在这个向量空间里：
- 词向量的经典模型：**Word2Vec**（两种训练方式）
    - **Skip-gram**：   
        根据中间词预测上下文（给出"喜欢"，猜前后文"我"和"苹果"）
        - 输入：一个词
        - 输出：它周围的词  
    Skip-gram 在处理罕见词时效果更好。
    - CBOW：    
        根据上下文（周围的词）预测中间词（填空题：__ 喜欢 苹果 -> 我）
        - 输入：它周围的词
        - 输出：一个词
- 现代的进化：动态词向量（ELMo / BERT）  
    Word2Vec 是静态的：无论上下文，"苹果"永远只有一个向量。但它有歧义（"苹果手机" vs "吃苹果"）。
    现代模型（如 BERT）采用动态词向量：根据句子上下文实时生成向量，同一个"苹果"在不同的句子里向量值是不同的——这也是大语言模型（LLM）成功的秘诀之一。
