# 文件夹存储占用分析器 — PRD（产品需求文档）

## 1. 项目背景与目标

用户在日常使用电脑时，经常需要了解某个文件夹（及其内部子文件夹、文件）的存储占用情况，以便清理空间、定位大文件。目前系统自带工具只能看单层大小，缺乏直观的占比可视化与递归下钻能力。

本项目目标是提供一个**桌面小程序**，对任意文件夹进行递归存储占用分析，并以**扇形图（饼图）**的形式直观展示各子项占比，支持交互式下钻查看深层组成。

---

## 2. 功能需求

### 2.1 核心功能
- **递归统计**：对任意选定文件夹，递归统计其每个子文件夹**内部所有内容的真实占用字节数**，以及顶层文件的占用，而非仅统计直接子项。
- **占比可视化**：以饼图（扇形图）展示当前层级各子项（子文件夹 / 文件）的占用占比。
- **多级下钻**：双击饼图某个扇区，可下钻进入该子文件夹，重新绘制其内部组成饼图。
- **返回上一级**：提供「返回上一级」按钮，从下钻层级退回上一层。

### 2.2 输入方式（三种）
1. **输入地址**：在输入框粘贴/输入文件夹路径，点击「分析」按钮。
2. **浏览按钮**：点击「浏览」按钮，弹出系统文件夹选择对话框选择目标文件夹。
3. **拖拽文件夹**：将文件夹直接拖拽到程序窗口，自动触发分析。

### 2.3 展示细节
- **存储单位自适应**：根据文件/文件夹实际大小，自动选择最合适的单位展示（B / KB / MB / GB / TB），避免固定单位带来的阅读困难。
- **小占比合并**：占比小于 **1%** 的子项在饼图中合并为「其他」一项，避免饼图碎片化难以阅读。
- **小扇区文字隐藏**：占比介于 1%~3% 的扇区仍作为独立扇区展示，但**不显示名称与百分比**（避免文字遮挡/过小），悬停时再显示详情。
- **层级信息**：展示当前分析的路径，以及当前层级总占用大小。
- **界面美观**：采用统一主题配色（主色 `#3b6fd4` + 浅灰背景），含标题栏、图标化按钮、拖拽提示条与分区边框，提升视觉体验。

### 2.4 交互反馈（悬停 / 点击）
- **悬停扇区**：命中扇区放大高亮（其余降透明），并在该扇区旁浮动注释框显示「名称 / 大小 / 占比」；同时右侧明细列表自动高亮并滚动到对应行。
- **点击扇区**：单击时扇区瞬时加粗蓝色描边作为点击反馈（180ms 后恢复）。
- **双击扇区**：触发下钻（见 2.1）。
- **鼠标移出饼图**：高亮与注释消失，界面恢复常态。

### 2.4 扫描规则
- **忽略隐藏文件/文件夹**：以 `.` 开头的文件/文件夹，以及 Windows 下标记为「隐藏」属性的项，不参与统计。
- **无权限跳过**：遇到无访问权限的文件夹，自动跳过并在交互上给出提示，不影响整体分析继续。
- **不统计符号链接**（follow_symlinks=False），避免循环或重复计数。

## 3. 非功能需求 / 范围界定

| 项目 | 说明 |
|------|------|
| 运行形式 | 桌面应用（GUI 窗口） |
| 技术栈 | Python + Tkinter（界面） + matplotlib（饼图） |
| 最近历史 | **不需要**保存最近分析历史 |
| 结果导出 | **不需要**导出图片 / CSV / Excel 等 |
| 交互方式 | 双击扇区下钻；「返回上一级」按钮回退 |

---

## 4. 交互流程

```
启动程序
  │
  ├─ 用户通过 [输入地址+分析] / [浏览按钮] / [拖拽文件夹] 指定目标文件夹
  │
  ├─ 程序递归扫描（忽略隐藏项、跳过无权限项）
  │
  ├─ 绘制当前层级饼图 + 显示路径与总大小
  │
  └─ 用户操作
        ├─ 双击某扇区（非"其他"）→ 下钻进入该子文件夹，重绘饼图
        ├─ 点击「返回上一级」→ 退回上一层（若已在顶层则禁用）
        └─ 重新指定文件夹 → 重置分析
```

## 6. 数据结构（参考）

- 扫描结果：`{子项名称: 占用字节数}`
- 饼图数据：占比 < 1% 的项合并为「其他」；返回 `labels / sizes / label→原始名称映射`
- 下钻栈：`path_stack` 记录每一层路径，用于「返回上一级」

---

## 7. 验收标准

1. 给定任意文件夹，程序能正确递归统计各子项真实占用，与系统总大小一致（忽略隐藏项后）。
2. 饼图准确反映各子项占比，小占比（<1%）正确合并为「其他」。
3. 双击扇区可正确下钻，返回按钮可正确回退，路径与总大小随层级更新。
4. 三种输入方式（地址、浏览、拖拽）均可正常触发分析。
5. 隐藏项被忽略，无权限文件夹被跳过并有提示，程序不崩溃。
6. 大小单位随数据自适应显示。
7. 占比 1%~3% 的小扇区不显示文字标签，悬停时浮动注释显示名称/大小/占比，无遮挡。
8. 悬停扇区有放大高亮与右侧列表联动反馈；单击扇区有描边点击反馈；界面采用统一美观主题。
