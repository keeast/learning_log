## 2. 模块拆分与实现顺序

### 阶段一：基础工具函数（无界面）
**目标**：完成文件扫描与数据整理，先保证数据正确。

- [ ] **`human_size(num_bytes)`**
  - 输入字节数，按 B/KB/MB/GB/TB/EB 自动换算，保留两位小数。
  - `<1024` 返回 `xxx B`；否则逐级除以 1024，到 `<1024` 停。

- [ ] **`is_hidden(path)`**
  - 以 `.` 开头 → 隐藏。
  - Windows 下用 `ctypes.windll.kernel32.GetFileAttributesW` 判断 `FILE_ATTRIBUTE_HIDDEN`（值 2）；异常时忽略。

- [ ] **`_dir_size(path)`**
  - 递归累加文件夹内所有**非隐藏**文件大小；跳过无权限/出错项；不跟随符号链接（`follow_symlinks=False`）。

- [ ] **`scan_directory(root_path)`**
  - 用 `os.scandir` 遍历 `root_path` 直接子项（忽略隐藏）。
  - 子文件夹 → 调用 `_dir_size`；文件 → `stat().st_size`。
  - `PermissionError/OSError` → 弹 `messagebox.showwarning` 并跳过。
  - 返回 `{名称: 字节数}`。

- [ ] **`build_chart_data(items)`**
  - 计算总大小；按大小降序排列。
  - 单项占比 `< 0.01`（1%）累加进 `others`。
  - 返回 `labels`（含可能的"其他"）、`sizes`、`mapping`（label→原始名称，其他=None）。

**自检**：用一个小测试文件夹（含嵌套、隐藏文件、无权限目录）验证 `scan_directory` 与 `build_chart_data` 输出正确。

---

### 阶段二：GUI 骨架
**目标**：搭出窗口与输入区，能选文件夹并显示路径。

- [ ] 创建 `FolderAnalyzerApp` 类，`__init__` 初始化：
  - `self.current_path`、`self.path_stack`、`self.current_items`、`self.current_mapping`。
- [ ] **顶部输入区**（`_build_ui`）：
  - `ttk.Entry` 路径输入框（宽度自适应）。
  - 「浏览...」按钮 → `filedialog.askdirectory` → 填入输入框并触发分析。
  - 「分析」按钮 → 读取输入框路径 → `analyze(path)`。
  - 拖拽区 Label 提示「拖拽文件夹到此处」。
- [ ] **信息栏**：显示当前路径、总大小、「↑ 返回上一级」按钮（顶层时 `disabled`）。
- [ ] **主区域**：左侧 matplotlib 饼图 `FigureCanvasTkAgg`；右侧 `ttk.Treeview` 明细列表（列：名称 / 大小 / 占比）。

---

### 阶段三：分析与绘图联动
**目标**：选好文件夹后正确出图与列表。

- [ ] **`analyze(path)`**
  - 校验路径存在且为目录，否则 `messagebox.showerror`。
  - 重置 `path_stack=[]`，设 `current_path=path`。
  - 调 `scan_directory` → `build_chart_data` → 存 `current_items/mapping`。
  - 调 `draw_chart()` 与 `fill_list()`，更新信息栏与返回按钮状态。

- [ ] **`draw_chart()`**
  - 清空旧 `Figure`，画 `pie(sizes, labels=labels, autopct=占比%)`。
  - 标题显示当前文件夹名。
  - `canvas.draw()`。
  - 绑定饼图扇区双击事件（matplotlib `pick_event` 或 `'button_press_event'` 命中检测）→ `on_sector_double_click(event)`。

- [ ] **`fill_list()`**
  - 清空 Treeview，按 `current_items` 插入行：名称、`human_size(大小)`、`占比%`。
  - "其他"项也列出（大小=累加值）。

---

### 阶段四：交互（下钻 / 返回 / 拖拽）
**目标**：完成 PRD 规定的全部交互。

- [ ] **`on_sector_double_click(event)`**
  - 取被双击扇区 label；经 `mapping` 得到原始子文件夹名。
  - 若为"其他"或映射为 None → 忽略。
  - 否则：`path_stack.append(current_path)`，`current_path = os.path.join(current_path, name)`，重新 `scan_directory` → 绘图 → 列表 → 启用返回按钮。

- [ ] **`go_back()`**
  - 若 `path_stack` 非空：弹出栈顶作为 `current_path`，重新分析当前层；否则禁用返回按钮。

- [ ] **拖拽支持**
  - Windows 下 Tkinter 拖拽：`root.drop_target_register('*')` + `root.dnd_bind('<<Drop>>', handler)`（需 `tkdnd` 时回退方案：用 `WM_DROPFILES` 消息绑定）。
  - 解析拖入路径 → 若为文件夹 → `analyze(path)`；否则提示。
  - *备选*：若环境不支持原生拖拽，明确在界面提示「请用浏览或输入地址」，并在 PRD 备注。

## 3. 关键实现要点（防坑）

| 要点 | 说明 |
|------|------|
| matplotlib 后端 | 用 `TkAgg`，`matplotlib.use("Agg")` 不必（TkAgg 需 Tk），直接 `FigureCanvasTkAgg`。 |
| 中文字体 | 配置 `font.family` 为 `Microsoft YaHei` 等，避免中文乱码；`axes.unicode_minus=False`。 |
| 饼图命中 | 抽取 `_hit_wedge(event)`：圆内判定 + 角度换算 `(90-angle)%360` 匹配 `wedge.theta1/theta2`，悬停与点击共用。 |
| 小扇区隐藏 | `SMALL_LABEL_RATIO=0.03`：低于该占比的扇区 `label=""` 且 `autopct` 返回 `""`，避免遮挡。 |
| 悬停反馈 | `_highlight_wedge` 放大+降透明度；`_show_annot` 浮动注释；`_select_in_tree` 联动右侧列表。 |
| 点击反馈 | `_flash_wedge` 瞬时描边（180ms 恢复）。 |
| 递归性能 | 大文件夹可能慢，扫描放在主线程即可（PRD 未要求异步）；如卡顿可后续加 `threading`，本期不做。 |
| 符号链接 | 全程 `follow_symlinks=False`，避免循环。 |
| Windows 拖拽 | 原生 Tkinter 无拖拽，需用 `ctypes` 注册 `WM_DROPFILES` 子类化窗口过程。注意 64 位下 `GetWindowLongPtrW` 的 `argtypes/restype` 须声明为 `c_uint64`，否则指针截断导致 `access violation`。 |
